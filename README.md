# Interactive Calculator & Unit Converter

## Project Description
This project is a beginner-friendly Python command-line calculator and unit converter developed for InternCircle Project 01.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Kilograms to Pounds conversion
- Input validation using while loops
- Handles division by zero
- Menu-driven interface

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.10 or newer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

   `python calculator.py`

## Unit Conversions
- 1 km = 0.621371 miles
- Fahrenheit = Celsius × 9/5 + 32
- 1 kg = 2.20462 pounds
